Scrcpy Options

Option Description Default / Notes
-b, --video-bit-rate Sets video encoding bitrate (bits/sec). Supports K (×1000) and M (×1,000,000). Default: 8M (8,000,000)
-m, --max-size Limits width/height of video while preserving aspect ratio. Default: 0 (no limit)
--max-fps Caps frame rate of screen capture. Default: uncapped / device dependent
--no-audio Disables audio forwarding. Audio enabled by default (if supported)
--no-mouse-hover Prevents forwarding mouse hover (movement without clicks). Hover events are forwarded by default
--no-power-on Does not wake/power on device when scrcpy starts. Device is powered on by default
--power-off-on-close Turns off device screen when scrcpy exits. Disabled by default
-r, --record Records screen output to a file (format inferred from extension or option). No recording by default
-S, --turn-screen-off Turns device screen off immediately while mirroring continues. Screen stays on by default
-t, --show-touches Shows touch indicators on device during use. Disabled by default
--video-codec Selects video codec (h264, h265, av1). Default: h264
--video-source Selects video source (display or camera). Default: display
-w, --stay-awake Keeps device awake while plugged in during scrcpy session. Disabled by default
--window-borderless Removes window borders for a clean display window. Standard window borders enabled
